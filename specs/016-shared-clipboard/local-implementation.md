## Adapter D1 autenticado

[RuntimeStore](../../src-tauri/src/storage/shared.rs) exige init explícito/versionado, sobre AppStorage supplied por host; rechaza stores legacy sin versión, nunca se inicia en MIGRATIONS. Subscribe comienza deshabilitado. Grants de host no serde, con revision/epoch monotónicos; cambiar/revocar pausa e invalida generaciones. VerifiedText no retiene la key usada al descifrar: el adapter verifica de nuevo la firma con la public-key **actual**, bajo el mismo mutex/transacción que valida generación/cursor/TTL, reserva ledger de ordinal por origen/epoch y guarda receipts/cursor. Retry exacto de página es idempotente, alteraciones/collisions/replays revierten todo; u64→timestamp i64 checked. Guarda JSON ciphertext una vez y limita la página agregada a 2 MB.

Import built-in sólo bajo policy de metadata e historial habilitado; receipt/grant/TTL/generation actuales, captura armada intacta y dedupe sin mover metadata. Guarda import, high-water, intento final y report pendiente en una transacción; missingFolder registra fallo durable sin reroute. report_pending entrega sólo metadata (máximo 50) y ack es scoped/idempotente, sin repetir import. La etiqueta live de este adapter es clasificación candidata, **no prueba lease/elapsed ni permiso nativo/acción**. No se exponen claims reales ni booleano de executor detenido a este wrapper.

Ocho tests autenticados y 26 regresiones SQLite pasan: grant/key actuales, revoke entre open/admit, fence viejo, replay/collision con rollback, retry exacto, timestamp/expiry, cap agregado y history/report/reopen. Pendientes acotados: metadata pending/rejected/resolve, wrapper de gaps/retención, outbox y claims nativos/Actions. No presentar esta API como runtime activado.
