# Pi Extension Stack — Historia

Esta referencia sólo ayuda a interpretar tracks antiguos que mencionan CodeMapper, FFF, taskflow, Pi Lens, Pi Footer, Cua Driver o research tools de Pi. No define routing actual, defaults, instalación ni modos de ejecución.

El inventario global permanece manager-only en `C:/dev/os/docs/reference/pi-extension-stack-inventory.md` y no es dependencia local de Copicu. No hay superficie activa `.pi` en este repo.

La selección de modelos, effort, tools, browser, todos, agentes, planificación, paralelización, idioma, estilo y modos pertenece a OMP. Las skills locales versionadas en `docs/skills/`, el comando opt-in `/research` y el built-in `computer` se conservan por su propósito local.

Los gates vigentes no provienen de este historial: consultar `AGENTS.md` y `docs/topics/agent-tool-routing.md`.
