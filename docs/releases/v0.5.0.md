# Copicu v0.5.0: Folders and Persistent Working Sets

Copicu adds hierarchical folders and makes the difference between temporary selection and persistent marks explicit. Keep the compact picker for quick reuse, organize clips without changing their tags, and collect a working set across searches.

Copicu remains Windows-first alpha software. This is a stable update channel release, not a claim of production maturity.

## New: Hierarchical folders

- Browse **All history**, unfiled clips in **Root (`/`)**, or a folder's direct clips in a collapsible tree.
- Create, rename and move folders; move a clip or selected group through its menu or drag it onto a folder or Root.
- Search and Find stay inside the browsing scope. Changing folders preserves the applied filter and any unapplied query draft.
- Use **Ctrl+P** to switch folders, **Ctrl+B** to collapse/reopen the tree, or `/` completion to insert a folder query. Tree navigation works with the keyboard and adapts to narrow picker windows.
- Explicitly arm a capture destination when you want new clips to enter a folder. Browsing alone does not redirect captures. Switching folders disarms it; reopening the picker preserves it during the process session; restarting returns capture to Root.
- Content deduplication stays global: copying an existing clip does not duplicate it or silently move it into the armed folder.
- Folder deletion asks separately whether to retain/delete clips and retain/delete descendant folders, with exact affected counts. Default behavior retains clips and subfolders.

## Improved: Selection and marked working sets

- Ctrl/Shift and row checkboxes build the same temporary selection. Flags build a separate persistent marked set that survives searches, hiding the picker and restarts.
- Separate counted **Add to marks** and **Remove from marks** commands handle mixed selections without guessing intent. Clearing marks never deletes clips.
- The marked menu shows the global total, marks in loaded results and how many are outside those results before metadata, batch actions or deletion. Global marked actions wait for every page of the marked set.
- Automatic refresh and marking updates retain valid selected IDs from later loaded pages, even after scrolling back to the top. Deleted clips and clips that no longer match the applied filter leave the selection.
- Selected row checkboxes stay visible without hover. `marked`/`unmarked` are the canonical query completion names; `checked`/`unchecked` remain valid compatibility aliases.

## Retention and search polish

- Marked, Inbox and foldered clips, including image blobs and thumbnails, are protected from automatic count retention. They do not consume the ordinary Root-history budget. This count is **not** a total disk-size limit.
- Removing marks or moving clips to Root restores normal retention eligibility on the next pruning pass unless another protection applies. Explicit deletion still deletes protected clips.
- Tab accepts query completions while keeping search focus; Shift+Tab remains available for focus navigation.
- Public docs and synthetic picker screenshots now show the current folder and working-set workflows. The release helper separates readable full notes from the short updater summary and makes dry-run planning side-effect-free.

## Upgrade notes

The local SQLite schema gains folders and folder membership. Existing clips migrate to Root without changing tags, Inbox or marks.

Before upgrading, quit Copicu fully from the tray and back up the app data directory, including SQLite and its associated blob files. Database migrations are forward-moving; an older executable is not a supported rollback after migration. Keep a pre-upgrade backup if you need to return to an older version. Capture destination is session-only and is not restored after restart.

## Scope and limitations

- Windows x64 NSIS installer. Installer, Tauri updater signature and `latest.json` are published together.
- Windows Authenticode signing is not enabled; SmartScreen warnings remain possible. The Tauri updater signature is separate and does not make the executable Authenticode-signed.
- Optional AI uses your configured provider; operations that read selected content can send it to that provider. The assistant defaults to YOLO; choose Confirm for per-operation approval. Local scripts are trusted code, not a sandbox.
- Paste/focus behavior remains Windows- and target-app-dependent. Test with non-sensitive clips.
- A sortable Explorer-style table/history-manager view is **not** part of this release.
