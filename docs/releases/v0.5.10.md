# Copicu v0.5.10: Clip files, ZIP and optional AI names

## Changes

- Save explicitly selected clips or all marked clips from their standard menus.
  Marked export includes every page, independently of the current filter or
  virtualized rows. A contextual single-clip action is explicit, not an active-item
  fallback for an empty selection.
- Write stored plain text as UTF-8 TXT and validated image blobs as PNG, either as
  loose files or a compressed ZIP. Unsupported representations are reported.
- Keep safe ordinal names, resolve Windows filename collisions without replacing
  existing files, and leave source contents, metadata, marks and clipboard intact.
- Choose a default destination or remember the last successful folder separately;
  always confirm destination. Optionally open it after saving, or use the manual
  button in the completion dialog.
- Show progress, cancellation, warnings and per-item details in a transient dialog.
  Closing it restores the clean picker and search focus. Cancelling a ZIP discards
  its prepared entries; only a finalized, synchronized package is published.
- Optionally generate text filenames with an independently selected AI model.
  Existing provider/credentials are reused; each export asks for disclosure
  approval. Sensitive-data detection is conservative, not a guarantee. Do not
  include secrets, credentials or personal data. Images stay local and retain
  conventional names; failures fall back without preventing a local save.
- Choose general/export models by name from an explicitly loaded provider catalog,
  using current unsaved provider settings. No need to memorize model IDs or save
  and reopen Settings first. Catalog failure remains retryable; no idle requests.
- Preserve additional synthetic Fixvox transient-transport regression tests and
  its documentation. These do not change clipboard runtime or certify the pending
  Fixvox producer installation/native acceptance.

Optional scripts, assistant and model-catalog lookup use the existing Node.js
runtime on PATH; NSIS does not install Node. Native text/image/ZIP export does
not require it. No new runtime tool is installed by this release.

Limits: 1–10,000 distinct clips, 32 MiB per clip and 512 MiB per export. ZIP is not a
recoverable backup. Rich formats, referenced external files, folder/search scopes,
public export scripting APIs and AI image naming are not included. Hard termination
can leave the export's own `.tmp`; it does not publish an incomplete final ZIP.
