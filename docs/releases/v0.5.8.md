# Copicu v0.5.8: Sharing diagnostics and picker Settings

## Changes

- Explain Sharing failures with a relevant message, the effect on sending or
  receiving, and a suggested next step. Distinguish protected keys, local storage,
  configuration, service availability, authorization and rejected requests.
- Show **Sharing needs attention** when synchronization fails. Keep device
  linkage separate from synchronization health, and show the same diagnostic in
  Settings and shared receptions.
- Reveal **Technical details** on demand: a stable error code, operation, safe
  cause, last failure time and affected shared clipboard when available.
  **Copy diagnostic** works with mouse or keyboard and offers manual selection
  if copying fails. The report excludes clipboard contents, credentials, keys,
  HTTP response bodies and profile paths.
- Keep retry guidance consistent with pause state. A successful sync clears its
  diagnostic while preserving independent effect failures. Rejected publications
  are not automatically resent.
- Move Settings to the first button in the picker's right control group and use
  a horizontal sliders icon. The X still hides the picker; Quit remains in the
  tray.

**Check status** reads the current status without sending clipboard content or
changing connections, pause state or effects. Existing folder policies and
Windows clipboard opt-ins are preserved.
