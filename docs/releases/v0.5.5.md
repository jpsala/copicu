# Copicu v0.5.5: Picker Context Menu

The picker's item context menu closes when choosing an action, including marking
or unmarking a clip. The menu remains closed after the history refreshes.

Right-clicking inside the custom menu prevents WebView2 from opening a second
native menu. Clicking a menu header preserves focus, so Escape still closes it.
