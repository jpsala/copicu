# Copicu v0.5.1: Resizable Folder Sidebar

Adjust the space between folders and previews, keep your preferred width across restarts, and open folder actions where you expect them.

Copicu remains Windows-first alpha software. This is a stable update-channel release, not a claim of production maturity.

## Resizable folders

- Drag the thin, straight sidebar/feed divider. A comfortable invisible hit target shows the resize cursor without making the border thicker.
- With the divider focused, Left/Right adjust 10 px, Shift adjusts 40 px, Home/End reach the limits and Escape cancels an unfinished adjustment.
- The preferred width is stored in Settings/SQLite when the adjustment finishes, not on every pointer movement. Reopen and restart restore it.
- Default 214 px, minimum 140 px and ceiling 600 px. The effective maximum reserves 320 px for the feed. Smaller windows clamp the layout temporarily without overwriting your saved preference; windows up to 560 px keep the existing overlay.
- Folder indentation is now 10 px per level. Long names can be truncated visually; their complete paths remain available in tooltips.

## Correctly anchored folder actions

Right-click menus open beside the pointer, the dots open actions below their button, and Shift+F10 anchors them to the folder row. Menus now live outside the transformed sidebar, avoiding the extra header offset. Arrow navigation, Escape and focus return remain available; collapsing the tree closes its menu.

## Upgrade and scope

- Compatible with existing Settings: a missing sidebar width uses the existing 214 px default. Valid existing preferences are preserved. No new database migration is needed for this preference.
- Back up your app data directory, including SQLite and blobs, before upgrading. Never use real clipboard history as a disposable test fixture.
- No Explorer table, favorites system, clipboard routing changes or new dependencies are included.
- Windows x64 NSIS installer, Tauri updater signature and `latest.json` are published together. Authenticode signing is not enabled; SmartScreen warnings remain possible. Updater signing is separate.
- These UI fixes do not establish that an unrelated intermittent hang is resolved. Native paste/focus behavior remains target-dependent.

## Verification

Renderer regression tests cover pointer/keyboard limits, cancel/blur/unmount, focus and selection, persistence failures, narrow overlays and viewport menu geometry. Rust verifies preference normalization and SQLite reopen with synthetic temporary data. Strict Vite chunk checks pass without increasing the limit. Release/post-install evidence is recorded in track 040; native claims are limited to the smoke actually executed.
