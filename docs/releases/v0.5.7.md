# Copicu v0.5.7: folder copies, Sharing and picker windows

Windows release verified on October 5, 2026. Local installation is separate.

## Changes

- Keep independent copies of the same text or image in different folders, with
  separate titles, notes and tags. Deduplication applies within each destination,
  including Root. The history migration preserves existing IDs and metadata.
- **Copy to folder** keeps the originals and reuses content already in the
  destination without overwriting its metadata. Conflicting moves fail together
  without silently merging or losing clips.
- Show where Sharing saved a reception and distinguish new content from a repeat.
  Repeated receptions regain recency without adding another copy in that folder.
- Put General before Sharing in Settings. Show the account, this PC, folder
  connections and recent activity first; expose Windows clipboard updates,
  shortcuts and scripts separately. Editing keeps existing connection identities
  and applies behavior changes to the current configuration.
- Open Settings from the picker's left gear button. The X hides the picker;
  Quit remains in the tray. Compact menus prioritize editing and group organizing
  and advanced actions, with keyboard and touch support.
- Coordinate Settings, metadata, Assistant, preview and Output with the picker.
  Preserve window positions, restore focus to the initiating window when
  appropriate, and keep background Output from taking foreground focus.
- Keep explicit search results when a delayed picker refresh overlaps their
  commit. Background validation uses the current descriptor and generation.

Saving a shared reception does not implicitly enable Windows clipboard writes.
Connecting a folder does not import earlier publications. Existing account
admission and the deployed Sharing service are unchanged.

## Verification and distribution

The final source passes 401 Rust tests (one optional benchmark ignored), 532
renderer cases across desktop and narrow layouts (two opt-in screenshot captures
skipped), 42 UI/model unit tests, 63 Sharing tests with 684 assertions, 83 Node
runner/helper tests, and the documentation checks and their 15 fixture tests.
TypeScript and the normal Vite production build pass.

The signed NSIS installer contains an x64 GUI executable and 154 extracted files.
Bundled WebView2 loader, scripts, helpers and TypeScript resources match their
sources. The updater signature and trusted comment verify cryptographically
against the project's public key; the UTF-8 manifest points to `v0.5.7` and
contains the matching signature. The normal frontend contains no visual-test
bridge. Updater signing is separate from Authenticode.

Six checks of the extracted shipping executable pass: startup/version, independent
folder copies and duplicate reuse, atomic rejection of conflicting moves, menus,
mark persistence after reload, and Sharing settings. Eleven native Windows cases
pass for global hotkey/input, Settings, pinned windows, geometry, minimizing,
metadata, Assistant, preview and background Output. Both suites use synthetic
profiles with capture, startup, updater and AI disabled; neither reads or writes
the real clipboard. Native paste was explicitly skipped.
