# Copicu v0.5.9: Bundled scripts and YouTube titles

## Changes

- Install all 35 shipped scripts, rather than only two, and include TypeScript
  definitions alongside active and inactive scripts.
- Enable combining clips, metadata, search, copy/paste, shared clipboard and
  technical examples by default in new installations (28 scripts).
- Install seven text/URL tools in `Scripts/disabled`, outside non-recursive
  discovery. Move a script between that folder and its parent to change its
  activation state. Upgrades preserve existing files in either location,
  including edits and previous activation choices; uninstall leaves them alone.
- Add an optional YouTube video-title script. Once enabled, it sends only the
  video ID to YouTube oEmbed, times out after five seconds and fills an empty
  title without changing the URL, tags, notes or clipboard. Existing titles skip
  the lookup; the item is re-read before updating to respect edits during fetch.
  This read/write pair is not an atomic compare-and-set.

Active scripts retain their declared triggers. In particular, global shortcuts
are registered subject to normal conflict checks, and technical examples
015/027 run on matching clipboard captures. Sharing examples remain gated by
real channel IDs, grants and explicit subscription/writer permissions; the
installer does not configure channels or authorize sending/receiving.

The installer targets `Documents/Copicu/Scripts`. Users with a custom scripts
folder must move the installed structure to their configured location. Removing
both copies of a bundled script permits reinstall on upgrade; move it to
`disabled` for durable opt-out. The legacy 004 URL-opening example remains
inactive and requires an unsupported host capability; installation does not make
that example ready for native URL opening.
