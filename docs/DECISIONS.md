# Decisiones Anteriores: Referencia Histórica

Este archivo es compatibilidad para referencias previas, no un registro global activo. El [original íntegro](reference/os2-legacy/DECISIONS.md) conserva decisiones, razones y fechas anteriores byte a byte. No editar el archivo histórico ni ejecutar sus permisos, comandos AOS/OMP, planes o propuestas como instrucciones actuales.

Las nuevas decisiones viven con sus razones en el topic pertinente. Para conocer el contrato del producto, abrir su fuente temática y las secciones necesarias; una decisión histórica `accepted` o `superseded` no prueba estado actual ni autorización de ejecución.
